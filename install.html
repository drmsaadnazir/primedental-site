Installing Prime Dental

It takes about a minute. Windows will show you two security messages along the way — that is normal for any newly released software, and this page shows you exactly which button to press each time.

Why the warnings appear. Windows keeps a running count of how many people have downloaded a given program. Prime Dental is new and installed by a small number of clinics, so that count is low and Windows says it "couldn't verify" the file. It is a statement about how common the download is — not a sign that anything is wrong with it.

  1. Download the installer

    Open the link Dr. Saad sent you. The file is named something like Prime Dental_1.6.55_CLIENT_x64_en-US.msi and is about 5 MB.

  2. Edge asks you to confirm the download

    A panel appears saying the file "isn't commonly downloaded". Both of the obvious buttons here mean "do not install" — the one you want is hidden.

    Make sure you trust Prime Dental_1.6.55_CLIENT_x64_en-US.msi before you open it
    Microsoft Defender SmartScreen couldn't verify if this file is safe because it isn't commonly downloaded.
    Publisher: Unknown
    Cancel Delete  ⌄
    ↑ Click the small ⌄ arrow next to Delete, then choose Keep.

    If it asks a second time, choose Show more → Keep anyway.

  3. Open the file

    Double-click the downloaded .msi file, from the Downloads panel or your Downloads folder.

  4. Windows shows a blue box

    "Windows protected your PC". The Run anyway button only appears after you click the small link on the left.

    Windows protected your PC
    Microsoft Defender SmartScreen prevented an unrecognised app from starting.
    More info Don't run
    ↑ Click More info first — then a Run anyway button appears.

  5. Finish the installation

    Accept the default options and click through. Prime Dental then appears in your Start menu. Your data stays on this computer — nothing is uploaded anywhere.

If something does not look right

You only see "Cancel" and "Delete"Click the ⌄ arrow on the Delete button. "Keep" is inside that menu.
The blue box has no "Run anyway"Click More info first. The button appears underneath.
"This app can't run on your PC"You need 64-bit Windows 10 or 11. Most computers from the last several years qualify.
Your antivirus removed the fileRestore it from quarantine, or ask Dr. Saad to bring it on a USB stick instead.
You would rather avoid all of thisAsk Dr. Saad to install it in person from a USB stick — then Windows shows no warnings at all.

What you should not do

Do not click "Report this app as safe". It sends a review request to Microsoft and takes no effect on your installation. Just follow the steps above.
