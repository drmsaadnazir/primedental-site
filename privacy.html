🦷 Prime Dental

Privacy Policy

Last updated: 26 September 2026

Prime Dental is practice-management software for dental clinics, made by Dr. Saad Nazir ("we"). This page explains what happens to the information a clinic enters into the app, and what the optional Google Calendar connection does.

The short version: Prime Dental runs on the clinic's own computer. Patient records are stored on that computer and are never sent to us. The only time appointment details leave the computer is if the clinic chooses to connect its own Google Calendar.

1. Where clinic data is stored

Everything a clinic enters — patients, visits, treatment notes, prescriptions, payments, appointments, stock and registers — is saved on the clinic's own Windows computer. We do not run a server that holds clinic data, and we cannot see, access or recover it.

Backups are written to a folder the clinic chooses. If the clinic picks a folder that is synced by a service such as OneDrive or Google Drive, that service's own terms apply to the backup files.

2. What the app sends over the internet

Prime Dental works fully offline. When the computer is online, it may make these connections:

Update checkAsks our release page on GitHub whether a newer version exists. No clinic or patient data is sent.
FontsThe app may load display fonts from Google Fonts. No clinic or patient data is sent.
WhatsAppButtons such as "Remind" open WhatsApp with a message already typed. Nothing is sent until the clinic presses Send in WhatsApp.
Google CalendarOnly if the clinic turns it on — see section 3.

Prime Dental has no analytics, advertising or usage tracking.

Licence activation is done by exchanging a short code with us (for example on WhatsApp). That code identifies the computer; it contains no patient data.

3. Google Calendar (optional)

A clinic can connect its own Google account in Settings → Google Calendar so that appointments appear on the dentist's phone. It is off unless the clinic connects it, and it can be disconnected at any time from the same place.

What we ask Google for. Prime Dental requests one permission: https://www.googleapis.com/auth/calendar.events — to create, change and delete events in the connected account's calendar.

What we do with it. When an appointment is added or changed in Prime Dental, the app creates or updates a matching event in the account's primary calendar. When an appointment is cancelled, marked no-show or deleted, the app deletes that event. Each event contains:

  • patient name and the planned procedure and tooth number, or the appointment type when no procedure is linked (the event title)
  • date, time and the clinic name (the location)
  • the patient's phone number, the planned procedure and tooth, any appointment or follow-up notes, MR number and appointment status (the description). Fees are never sent.
  • a hidden reference number so the app can find the same event again

The app also reads the calendar's name once, to show the clinic which account is connected.

What we do not do. Prime Dental does not read, list, download, change or delete any other events in the calendar — only the ones it created. It does not access Gmail, Contacts, Drive or any other Google service.

Where the data goes. Data travels directly between the clinic's computer and Google. It does not pass through any server of ours, and we never receive or store it. The sign-in token is kept only on that computer and is not included in backups or exports. Disconnecting in Settings revokes the token and deletes it from the computer. You can also remove access at any time from your Google Account at myaccount.google.com/permissions. Events already created stay in your calendar until you delete them.

Limited Use. Prime Dental's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to show the clinic's own appointments in its own calendar. It is not sold, not used for advertising, not transferred to anyone else, and not read by any person except the clinic itself.

Appointment details placed in Google Calendar are held by Google under Google's own privacy policy. Clinics should only connect a Google account that belongs to the clinic.

4. This website

This website is hosted on GitHub Pages, which may keep standard server logs such as IP addresses. The demo video is embedded from YouTube in privacy-enhanced mode. The site uses no cookies or analytics of its own.

5. Responsibility for patient data

The clinic is responsible for the patient data it records in Prime Dental and for deciding whether to connect Google Calendar. Because the data never reaches us, requests from patients to see, correct or delete their records should go to the clinic.
